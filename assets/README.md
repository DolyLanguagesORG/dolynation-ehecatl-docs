# Assets

Binarios y documentos fuente que acompañan a la documentación: entregables en
Word/PDF, capturas, presentaciones y logos.

## Convenciones

- `kebab-case` y nombre descriptivo: `doly-nation-presentacion-final.pptx`,
  `captura-visor-lectura.png`.
- Agrupa por tipo si crece: `assets/documentos/`, `assets/capturas/`,
  `assets/logos/`.
- Los binarios **no se editan en GitHub**: se suben ya finales.
- Para texto, prefiere Markdown aquí y guarda el Word/PDF solo como entregable.
