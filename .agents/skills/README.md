# Skills — `dolynation-ehecatl-docs`

Skills (instrucciones para agentes de código) de este repositorio. Los agentes
las cargan bajo demanda a partir del `description` del `SKILL.md`.

| Skill | Para qué |
| ----- | -------- |
| [`doly-workflow`](./doly-workflow/SKILL.md) | Flujo global de la organización: repos, ramas (`develop`/`main`/`rc-*`), Conventional Commits, PR y checks, Kanban y releases. |
| [`anteproyecto`](./anteproyecto/SKILL.md) | Contexto del anteproyecto académico: problema, objetivos, requerimientos, metodología, roles, cronograma. |
| [`docs-style`](./docs-style/SKILL.md) | Cómo escribir y mantener esta documentación: estructura, tono, links relativos, tablas, diagramas. |

Estas son las skills **generales de la organización**. Cada repo de código
(`dolynation-atl-back`, `dolynation-tonatiuh-front`) tiene además su skill
específica (`nestjs-backend`, `nextjs-frontend`).
